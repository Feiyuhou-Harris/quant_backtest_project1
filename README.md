# quant_backtest_project1
Python momentum strategy backtesting framework with Pandas

## Quant Backtest Project: Momentum Strategy
This project implements a momentum trading strategy backtest using Python and Pandas.

## Project Overview
Momentum strategy assumes assets that have performed well in the past will continue to outperform in the near future.
The program processes historical market data, generates buy/sell trading signals, calculates portfolio returns and maximum drawdown to evaluate strategy performance.

## Key Features
- Clean and preprocess time-series market data
- Generate momentum trading signals based on historical price
- Calculate portfolio cumulative return, annualized return and max drawdown
- Visualize equity curve of the strategy

Python, Pandas, NumPy, Matplotlib
